# Support Desk

A customer support job application tracker built with HTML, CSS, and vanilla JavaScript.


## Run locally

Run `python -m http.server 8000` and open http://localhost:8000. On Windows, use `py` if needed.

Save roles, filter by work arrangement and status, compare job descriptions with a skills profile, draft application materials, and track interviews and follow-ups. Records and drafts are stored in your browser. Export a backup to move them between devices.
